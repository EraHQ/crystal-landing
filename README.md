# Crystal landing

The public front door for Crystal at crystal.erahq.ai. Pure static
HTML and CSS, no build step: what you see in the repo is what Vercel
serves.

- `index.html` — the landing page
- `privacy.html` / `terms.html` — the legal pages
- `styles.css` — the one stylesheet
- `favicon.svg`

The product itself lives at github.com/EraHQ/CRYSTAL; the console is
inspector.erahq.ai.
